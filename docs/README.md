# Documentation Map

This folder contains the core Card Asset Platform v2 planning/specification documents.

## Document-to-Implementation Mapping

- `Card_Asset_Platform_PRD_v2.docx` → Product requirements baseline for cross-cutting scope and acceptance criteria across `apps/api`, `apps/web`, and `packages/types`.
- `Card_Asset_Platform_HLD_v2.docx` → System architecture and integration boundaries, primarily guiding backend service design in `apps/api` and shared contract modeling in `packages/types`.
- `Card_Asset_Platform_Frontend_Spec_v2.docx` → UX flows, interaction behavior, and frontend state/data requirements for `apps/web`, with type dependencies in `packages/types`.
- `Card_Asset_Platform_LLD_v2.docx` → Detailed component/module design and implementation-level behaviors across `apps/api`, `apps/web`, and `packages/types`.

Use this mapping during implementation and review to quickly trace requirement source documents to the code areas they impact.
